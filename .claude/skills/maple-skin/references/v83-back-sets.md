# v83 `Map.wz/Back` sets: which place uses which

Read from the v83 map data in P0nk/Cosmic (`wz/Map.wz/Map/Map*/<id>.img.xml`, each map's
`back/*/bS`). `Back` holds only the far layers (sky, clouds, hills); houses, trees and fences
are `Map.wz/Obj`, ground is `Map.wz/Tile`.

Henesys's objects: `Obj/acc1.img` group `grassySoil` (trees, flowers, fences), `Obj/houseGS.img`,
`Obj/door.img`, `Obj/connect.img` (ladders); its tile is `Tile/woodMarble.img`.
Ellinia: `Obj/acc2.img` group `shineWood` and `Obj/houseSW.img`.

v83 has 107 Back sets in total; the rest are dungeon interiors, events and overseas maps.
