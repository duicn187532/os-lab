# DSA LAB｜資料結構與演算法互動式自學網站

適用於希望從硬體與記憶體開始理解資料結構、並親手觀察演算法逐步執行的人。

- **線上網址（需 OS LAB GitHub Pages 已啟用）**：https://duicn187532.github.io/os-lab/dsa/
- **原始碼**：https://github.com/duicn187532/os-lab/tree/main/dsa
- **離線執行**：開啟 `index.html`，不需 npm、不需後端。

## 課程

18 章、54 道測驗、14 類可互動演算法模擬。

課程順序：記憶體與資料 → Big-O → 陣列 → Linked List → Stack & Queue → Recursion → Binary Search → 基礎排序 → 分治排序 → Hash Table → BST → Heap → BFS/DFS → Dijkstra → Greedy → Dynamic Programming → Union-Find → 綜合選型。

每章包括：ELI5 比喻及限制、3 個技術重點、Python／C 程式碼、可設定輸入並逐步執行的模擬器、3 題附解析測驗及個人筆記。
