# DSA LAB｜資料結構與演算法互動式自學網站

[回到 CS LAB 首頁](https://duicn187532.github.io/os-lab/)｜[資料結構與演算法線上版](https://duicn187532.github.io/os-lab/dsa/)

適用於希望從硬體與記憶體開始理解資料結構、並親手觀察演算法逐步執行的人。繁體中文、完全靜態：18 章、18 種逐步實驗、54 題附提示與解析的測驗，附 Python／C 程式碼。

## 課程

| 單元 | 章節與互動實驗 |
| --- | --- |
| 硬體地基 · 分析基礎 | 電腦怎麼放資料？（**記憶體位址與快取行**：陣列 vs 鏈結串列的快取未命中）· 如何衡量演算法？（Big-O 成長階梯） |
| 線性結構 | 陣列與字串（插入、刪除、線性搜尋）· Linked List（重連 next）· 堆疊、佇列與 Deque（**同一串資料放進 Stack 與 Queue 比較取出順序**） |
| 演算法思維 | 遞迴與呼叫堆疊（階乘）· 二分搜尋 |
| 排序家族 | 基礎排序（Bubble、Insertion、Selection）· 分治排序（**Merge、Quick**） |
| 索引 · 階層結構 | 雜湊表（chaining、負載率）· BST 插入 · Min-Heap 上浮與下沉 |
| 網路結構 · 圖論進階 | BFS／DFS · **Dijkstra 最短路徑**（relaxation 與目前距離）· Union-Find 與路徑壓縮 |
| 演算法策略 | 貪心區間排程 · 動態規劃填表 |
| 能力驗收 | 綜合實戰（**需求驅動的資料結構選型**：操作次數 × 單次成本估計，淘汰不支援的結構再比較） |

粗體為遷移到共用 shell 時新增或修正的實驗：舊版有四組章節共用同一個實驗且預設值相同，畫面完全一樣（ch1／ch3 都是陣列插入、ch2／ch18 都是 Big-O、ch8／ch9 都從 Bubble Sort 開始、ch13／ch14 都從 BFS 開始），堆疊章節也只有一步。

## 使用方式

- 每章分為 ① 觀念（ELI5 類比、深入原理、比喻的極限、程式碼、自己的解釋）→ ② 實驗 → ③ 測驗。
- 實驗可調整輸入、逐步前進或回看，也可自動播放；點步驟列表可直接跳到任一步。
- 測驗每題兩次機會，第一次只給提示；答錯的題目進入錯題本，可在「錯題複習」再練或做跨章節混合練習。
- 進度、筆記與錯題本存在目前瀏覽器的 localStorage（鍵值 `dsa.progress`）。第一次開啟時會匯入舊版的 `dsa.complete`、`dsa.answers`、`dsa.notes`、`dsa.theme`：已完成章節、筆記、主題保留，最後一次答錯的題目放進錯題本；舊鍵不會被修改。可在「我的筆記」頁備份與還原。

## 檔案

- `index.html`：頁面，只載入下列檔案與共用 shell（`../shared/`）。
- `assets/content.js`：18 章教材與 54 題（由舊版單檔逐字拆出，依單元排序；每題的提示為遷移時新增）。
- `assets/course.js`：課程設定與舊進度匯入。
- `assets/labs.js`：上半部是舊版的實驗程式（`configFor` 定義輸入、`makeFrames` 產生步驟、`viz` 繪圖），下半部是新增的專屬實驗與 `CSLab.frameLab` 轉接層。
- `assets/dsa-labs.css`：實驗視覺元件樣式（class 皆以 `dz-` 開頭）。

測試：在儲存庫根目錄執行 `python -m http.server 8000`，再執行 `node tests/dsa-review.cjs`。無模型 API、CDN、伺服器或第三方 JavaScript 依賴。
